# Installing Baudly

Baudly is distributed as a pre-built installer via GitHub Releases. No build tools or runtimes are required — just download and run.

---

## Download

Go to the [Baudly Releases page](https://github.com/Baudly-dev/.github/releases) and download the latest installer for your platform.

| Platform | Installer | Status |
|---|---|---|
| Windows (x86-64) | `.msi` or `.exe` (NSIS) | Available |
| macOS | `.dmg` | TBC |
| Linux | `.AppImage` / `.deb` | TBC |

---

## Windows Installation

1. Download the `.msi` or `.exe` installer from the [Releases page](https://github.com/Baudly-dev/.github/releases).
2. Run the installer and follow the on-screen prompts.
3. Baudly will be available from the Start Menu after installation.

> **Note:** Windows requires [WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/). This is bundled automatically by the installer on systems that do not already have it.

### Windows SmartScreen Warning

Because Baudly is in early release and the installer is not yet widely distributed, Windows SmartScreen may show a warning. To proceed:

1. Click **More info** on the SmartScreen dialog.
2. Click **Run anyway**.

This warning will disappear once the installer has been downloaded by enough users to build a reputation.

## Updating

Download the latest installer from the [Releases page](https://github.com/Baudly-dev/.github/releases) and run it over your existing installation. Settings and saved sessions are preserved.

---

## Uninstalling (Windows)

Go to **Settings > Apps > Installed apps**, find **Baudly**, and click **Uninstall**.
